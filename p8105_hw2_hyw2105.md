The cleaned dataset contains information on each entrance and exit of
NYC subway stations, including the subway line, station name, station
latitude and longitude, the routes served (`route1` to `route11`),
whether entry is allowed, vending availability, entrance type, and ADA
compliance. I imported the data with relative paths, specified `route8`
to `route11` as character at import so that all route variables share
the same type, cleaned the variable names, retained the relevant
variables, and converted `entry` from a YES/NO character variable to a
logical variable. The resulting dataset has 1868 rows and 19 columns.

These data are not tidy: route information is spread across 11 columns,
so the route number is stored in the column names rather than as its own
variable.

## Reformat route information

To make route number and route name distinct variables, I used
`pivot_longer()` to convert `route1` to `route11` into two variables:
`route_number` and `route_name`. Because most entrances serve only a few
routes, many of the route columns were empty; I removed rows with
missing `route_name`, since these do not correspond to any actual route.

``` r
subway_tidy_df =
  subway_df |>
  pivot_longer(
    route1:route11,
    names_to = "route_number",
    names_prefix = "route",
    values_to = "route_name"
  ) |>
  drop_na(route_name)
```

The data come from the September 2025 version of the Trash Wheel
Collection Data. For each trash wheel, I specified the sheet and the
cell range in `read_excel()` to skip the empty first row and exclude
non-data columns, cleaned the variable names, and removed rows without a
dumpster number (the grand total row at the bottom of each sheet). For
Mr. Trash Wheel, I rounded `sports_balls` to the nearest integer and
converted `year` from character to numeric so that it matches the other
two sheets. I added a `trash_wheel` variable to each dataset before
combining them with `bind_rows()`.

The combined dataset contains 1188 observations, where each row is one
dumpster collected by one of three trash wheels. Key variables include
the collection date (`month`, `year`, `date`), the weight
(`weight_tons`) and volume (`volume_cubic_yards`) of trash, and counts
of specific items such as `plastic_bottles` and `cigarette_butts`. Some
items were not recorded by every trash wheel: `sports_balls` is only
available for Mr. Trash Wheel, and `glass_bottles` is not recorded for
Gwynnda, so these values are missing for the corresponding rows. The
`month` variable also has some inconsistent formatting in the original
file (e.g., trailing spaces and lowercase entries).

For available data, Professor Trash Wheel collected a total of 282.26
tons of trash. Gwynnda collected a total of 18120 cigarette butts in
June 2022.

The baseline file contains a first line describing the coding of each
variable, so I skipped it at import. Missing values for age at MCI onset
are coded as `.` in the raw file, so I included `.` as a missing value
code. I cleaned the variable names and recoded `sex` (1 = male, 0 =
female) and `apoe4` (1 = carrier, 0 = non-carrier) from numeric codes to
descriptive character values, following the coding description in the
file. To meet the inclusion criterion of no MCI at baseline, I removed
participants whose age at MCI onset was less than or equal to their
baseline age.

A total of 483 participants were recruited. After removing 4
participants who did not meet the inclusion criterion, 479 participants
remained, and 93 of them developed MCI during follow-up. The average
baseline age was 65 years, and 30% of women in the study were APOE4
carriers.
