The cleaned dataset contains information on each entrance and exit of
NYC subway stations, including the subway line, station name, station
latitude and longitude, the routes served (`route1` to `route11`),
whether entry is allowed, vending availability, entrance type, and ADA
compliance. I imported the data with relative paths, specified `route8`
to `route11` as character at import so that all route variables share
the same type, cleaned the variable names, retained the relevant
variables, and converted `entry` from a YES/NO character variable to a
logical variable. The resulting dataset has 1868 rows and 19 columns.

These data are not tidy: route information is spread across 11 columns,
so the route number is stored in the column names rather than as its own
variable.
